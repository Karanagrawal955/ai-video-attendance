# AI Video Attendance backend - Python dependencies (Python 3.11+)

# GPU notes (READ THIS):
#   * `insightface==2.0` pulls in the CPU `onnxruntime` package and the GUI
#     `opencv-python` wheel as its own dependencies.  For GPU deployments you
#     swap them afterwards (this is the official InsightFace 2.0 recipe):
#
#       pip uninstall -y onnxruntime opencv-python
#       pip install onnxruntime-gpu==1.26.0 opencv-python-headless
#
#   The Dockerfile does exactly this automatically.  On a local machine run
#   `scripts/setup_gpu.ps1` (Windows) or `scripts/setup_gpu.sh` (Linux/macOS).
#
#   RTX 50-series (Blackwell, sm_120) notes - the pins here are deliberate:
#     * onnxruntime-gpu 1.26.0 is the NEWEST build still targeting CUDA 12
#       + cuDNN 9 (1.27.0 moved to CUDA 13, which needs driver >= 580).
#     * The Docker base image is CUDA 12.8.1 + cuDNN 9 (sm_120 support with
#       the Blackwell floor driver >= 570.xx).
#     * onnxruntime-gpu >= 1.21 is required for sm_120 (RTX 5060/5070/...).
#   If your driver is >= 580 you may optionally use onnxruntime-gpu>=1.27
#   with a CUDA 13 base image - see the README "GPU / CUDA" section.
